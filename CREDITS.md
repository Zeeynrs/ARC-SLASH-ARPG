## 🎮 Minecraft Reference & Fan Tribute Disclaimer

**Parallel Dungeons** is a free, non-commercial, open-source educational game created using pure Vanilla HTML5 Canvas and JavaScript.

Certain biome themes, enemy concepts, and boss mechanics in this project are inspired by and created as a tribute to **Minecraft** by **Mojang Studios / Microsoft Corporation**:

| Referensi / Reference | Lokasi di Game / In-Game Location | Deskripsi / Description |
| :--- | :--- | :--- |
| **Deep Dark Biome** | Stage 23 – 35 | Suasana lantai deepslate, partikel sculk moss, dan efek kegelapan atmosferik (*darkness vignette*). |
| **The Warden** | Stage 35 (Ancient Titan Boss) | Konsep monster titan tanpa mata dengan tanduk sculk resonan, detak jantung jiwa (*soul heart ribcage*), dan serangan *Sonic Cataclysm*. |
| **Sculk Entities** | Stage 23 – 34 | Monster bertema sculk seperti *Sculk Crawler*, *Sculk Zombie*, *Sculk Phantom*, dan *Sculk Spitter*. |
