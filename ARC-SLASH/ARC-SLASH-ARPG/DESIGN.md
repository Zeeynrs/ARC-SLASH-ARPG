# DESIGN SYSTEM: Arc Slash ARPG

## 1. Identity & Mood
- **Theme**: Retro 16-Bit Dark Fantasy Dungeon Crawler
- **Mood**: Gritty, mysterious, tactile, arcade-responsive.
- **Principle**: Solid crafted surfaces, zero artificial AI glow, zero tech-grid textures, zero pill-shaped glassmorphism.

## 2. Color Palette
- **Base Abyss**: `#080a0f` (deepest dark backdrop)
- **Dungeon Stone Surface**: `#111622` / `#182030` (panels, HUD, card bodies)
- **Forged Iron Borders**: `#2c394b` / `#3b4b66` (crisp 1-2px framing)
- **Antique Gold (Primary Accent)**: `#eab308` / `#f59e0b` / `#ffd700` (coins, stage titles, critical achievements)
- **Vitality Crimson**: `#dc2626` / `#ef4444` (player HP, danger cues)
- **Mana Cobalt**: `#0284c7` / `#38bdf8` (armor, shield, mystic energy)
- **Toxic Emerald**: `#059669` / `#10b981` (speed, poison, assassin traits)
- **Text Neutral**: Primary `#f8fafc`, Secondary `#94a3b8`, Muted `#64748b`

## 3. Typography
- **Primary Arcade / Game Font**: `'Press Start 2P', monospace` (for all in-game HUDs, stats, cards, badges)
- **Secondary Readable UI Font**: `'Outfit', sans-serif` (for browser controls and accessible hints)

## 4. Antislop Dials
- **ENERGY**: 2 (Steady arcade rhythm, clear hierarchy)
- **RHYTHM**: 2 (Consistent stone-chassis frames with distinct screen compositions)
- **MOTION**: 2 (Purposeful feedback for hits, hovers, cooldowns; no endless decorative ambient looping)
